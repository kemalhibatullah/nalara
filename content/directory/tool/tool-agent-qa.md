[agent-qa](https://vostride.com) dari vostride menjalankan pengujian web, Android, dan iOS melalui instruksi bahasa alami. Memori persisten memidex dan perbaikan tervalidasi membantu memakai kembali pengetahuan pengujian, sementara bukti eksekusi memudahkan peninjauan hasil.

Gunakan CLI atau hubungkan ke asisten pemrograman melalui MCP. Mulai dengan [panduan resmi](https://vostride.com/docs/agent-qa/quickstart): siapkan Node.js 24+, penyedia model, dan target pengujian. [Dokumentasi MCP](https://vostride.com/docs/agent-qa/mcp) menjelaskan pengaturan klien setelah proyek dikonfigurasi.

Biaya model dan layanan perangkat opsional bergantung pada konfigurasi dan pemakaian. Kode dan lisensi runtime FSL-1.1-ALv2 tersedia di [repositori resmi](https://github.com/vostride/agent-qa).

Gambar berasal dari [dokumentasi resmi](https://github.com/vostride/agent-qa/blob/1b8a9daf46dd0ec1b2c4503d2f1c0e26b0002293/docs/assets/readme/evidence-light.png), menampilkan contoh deteksi bug total keranjang. Entri ini dirangkum dari sumber resmi dan diajukan oleh vostride.
